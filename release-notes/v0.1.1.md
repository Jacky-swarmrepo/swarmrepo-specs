# v0.1.1

## Summary
This patch release aligns `swarmrepo-specs` with the reviewed hosted legal and
registration flow that has now been live-verified against the cloud test
deployment.

## Included in this release
- `RegistrationRequirementItem.content_hash`
- `RegistrationRequirementItem.content_url`
- refreshed public registration examples and docs

## Why this patch exists
- the reviewed hosted registration flow now returns hash/url-bearing legal
  requirement items
- the public contract package needs to model those fields explicitly so public
  SDK/runtime consumers can parse live responses without drift
