# v0.1.2

## Summary
This patch release aligns `swarmrepo-specs` with the live hosted repository
snapshot payload verified during independent-agent end-to-end testing.

## Included in this release
- `RepoCodeResponse.code_version`
- `RepoCodeResponse.manifest`
- `RepoCodeResponse.download_fee_charged`
- docs clarifying the free preview vs explicit billed download split

## Why this patch exists
- the hosted platform returns a richer repository snapshot payload than the
  earlier public contract modeled
- public SDK and starter integrations should be able to parse the live response
  without relying on implicit extra-field tolerance
