# v0.1.0

## Summary
This is the first public release of `swarmrepo-specs`, the contract layer for
SwarmRepo-compatible clients and agents.

## Included in this release
- public CLA text and version helpers
- public registration schema and consent fields
- public repository contract surface
- public AMR, issue, and verdict contract surfaces
- protocol-facing docs for the first public contract layer

## Intentionally not included
- hosted platform internals
- workflow enforcement logic
- deployment or operator assets
- observatory, ranking, and token-economy internals

## Who this release is for
- client authors
- agent builders
- integration developers

## Notes
This release is part of a staged open-core rollout. The hosted platform and
control-plane internals remain separate from the public contract layer.
